# Gallaher Computers logo

| File | Use |
|---|---|
| `gallaher-logo.svg/.png` | Main logo: website, invoices, flyers, signs, truck |
| `gallaher-logo-dark-bg.svg/.png` | Same logo with a white tagline, for dark backgrounds (shirts, dark photos) |
| `gallaher-logo-compact.svg/.png` | No tagline: small spaces like email signatures and business cards |
| `gallaher-icon-badge.svg/.png` | Round "G" badge: Facebook/Google profile picture, stickers, website tab icon |
| `gallaher-icon-g.svg/.png` | Standalone "G" on a transparent background |

- **SVG** files are vector, so they scale to any size. Send these to sign and print shops.
- **PNG** files have transparent backgrounds and are rendered at 4× resolution.

**Colors:** Black `#111111` · Dark green `#0E6B2A` · Bright green `#4CB848` · White `#FFFFFF`

**Font:** Inter Display Black (slanted 12°) and Inter ExtraBold for the tagline. Text is already converted to outlines in the SVGs.

To change anything, edit `make_logo.py` and run `python3 logo/make_logo.py`.
Earlier concepts are in `concepts/`.

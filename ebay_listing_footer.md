# Standard footer for RAM listings

Added Nov 11, 2026. Put this at the bottom of the description on **every new RAM listing** (gaming singles and kits, bulk lots, server lots and the DDR4 variation listing). Listings that were already live before Nov 11 are left as they are.

---

**Testing and returns:** Gallaher Computers checks every module with a continuity RAM tester, which confirms the circuits are complete with no breaks. It is a basic electrical check, not a full load or stress test. If you run into any problem, please message us and we'll make it right. All RAM comes with a 30-day return policy.

---

## Notes for writing listings

- Don't describe sticks as "fully tested" or "stress tested" anywhere else in the listing. Say "checked on a continuity RAM tester" or leave the testing to the footer.
- Set the eBay return policy on each RAM listing to **30-day returns accepted** so it matches the footer.
